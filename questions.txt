(1) Function filter1() and filter2() perform the same operation and return the number of pixels based on the condition. The only difference is the order of the loops. filter1() loops through the columns first and then the rows, while filter2() loops through the rows first and then the columns.
(2) From the plot, I can see that both filters take more time as the image size increases. Filter 2 performs better than Filter 1, and the difference becomes much more noticeable with larger images. For the largest image, Filter 1 takes around 0.031 seconds while Filter 2 takes around 0.016 seconds, so Filter 2 is almost twice as fast. The time varies a little between runs, but the difference is not very large.
(3) The Valgrind results show that both filters do almost the same number of memory accesses, But Filter 1 has many more D1 cache misses. Filter 1 had a 2.2% miss rate, while Filter 2 had only 0.7% miss rate. This happens because Filter 2 reads the pixels row by row, so it accesses memory sequentially and makes better use of the cache, while Filter 1 reads column by column and jumps around in memory. Because Filter 2 has fewer cache misses, it spends less time waiting for data from memory, so it is faster.
